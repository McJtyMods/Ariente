ARIENTE - FORGE 1.20.1 PORT HANDOFF
Updated: 2026-11-02

STATUS AND PURPOSE
==================
This is an INCOMPLETE development port, not a completed gameplay port or a
release candidate. Phases 1 through 3 have implementation and focused checks.
Phase 4 now has automated integration/resource/packaging evidence below, but
a full survival playthrough and sustained balance validation remain release
gates. Passing checks do not establish complete feature parity.

This file owns Ariente gameplay, machines, equipment, shared HoloGui work,
resources/recipes, rendering and packaging. Read ../ArienteWorld/PORTING.txt for
the dimension, cities, population, travel generation, city AI and editing tools.
Both documents are intended to let a future Codex session resume without chat
history. Equipment, progression, systems and phase-4 integration checkpoints
are recorded below, with their remaining gameplay and release limits.

HOLOGRAM WINDOW CONTROLS (2026-11-02)

  including secondary pages and panels without a manual. Mounted panels omit
  close/pin; only block-associated panels can pin. Equipment has close but no pin.

  changes, and unpinning restarts the full timeout. A server-session UUID allows
  chunk reloads to retain pins while reopening a world clears them. Destroying
  the block still removes its panel. Looking backward no longer resets timeout.

  Patchouli the question mark is omitted. Color pickers use Back to return to
  settings; the shared X always closes the complete panel. Display/module panels

  header has A-Z/count sort buttons; the player grid, label and hotbar sit lower
  behind a separator. Its component bounds include the header and lowered hotbar.
  Click scrolling jumps three columns; holding repeats every two ticks, compared
  with eight ticks for hovering. Sorting changes real server slots, preserves
  complete stacks and validates the viewer/revision and current storage snapshot.
- Block panels now track their opener's UUID, including through entity saves.
  Reopening uses the same unmounted entity for that player/block, applies the
  requested page and new position/facing, refreshes timeout/detection bounds,
